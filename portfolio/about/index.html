Hi, I’m Ryan Guo

I build AI products — end-to-end, from prompt engineering to production deployment.

I got into AI engineering because I believe we’re living through the biggest shift in how software gets built since the internet. LLMs aren’t just a tool — they’re a new substrate for applications. I focus on the practical side: taking research ideas (RAG, agents, MCP) and turning them into reliable, observable, cost-efficient products that real users depend on.

What I Work On

  • RAG Systems that go beyond naive vector search — hybrid retrieval, rerank, query rewriting, citation tracking, hallucination guardrails
  • AI Agents that don’t just chat but take action — tool calling, multi-step reasoning, human-in-the-loop escalation, confidence-based routing
  • MCP Protocol implementation — building the connective tissue between LLMs and the tools they need
  • Full-Stack AI Products — Spring Boot backends, Vue 3 frontends, observability with OpenTelemetry, containerized with Docker

I default to Spring AI and Java for production systems — strong typing, mature concurrency, and enterprise reliability matter when you’re serving hundreds of tenants at scale.

How I Learn

I go to the source: official docs, Anthropic/OpenAI research posts, and first-principles experimentation. AI tools (Cursor, Claude Code) amplify my workflow, but the judgment of what to build and why still comes from experience. I can pick up a new framework and ship a working prototype within a week.

Beyond Code

I’m a long-termist. I maintain an active GitHub contribution streak, publish technical writing on my blog, and keep my open-source projects alive and evolving. I believe the cycle isn’t build → ship → forget — it’s build → operate → share → improve.
